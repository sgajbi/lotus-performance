# Common Pack

## Purpose

This pack contains small shared vocabulary and utility modules used across the repository.

## Audience

- engineers looking for existing shared enums or helpers,
- agents avoiding duplicate local vocabulary,
- reviewers checking cross-module naming consistency.

## Maintenance Notes

- Keep this pack small and domain-neutral.
- Do not add application workflow or source-integration logic here.
- When a shared value becomes public API vocabulary, update OpenAPI examples, docs, and tests.
